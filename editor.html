Timeline keys
Mac: Cmd works wherever Ctrl is written, Option = Alt, Delete key = delete.
Touchpad (Mac + Windows): pinch = zoom where your fingers are · two-finger swipe left / right = move in time, up / down = rows · click-drag or three-finger drag (Mac) = move a block
Touch screen / iPad: two fingers = pinch zoom + move · one finger on empty space = move around · tap = red line · double-tap a sound = hear only it
Mouse: Ctrl / Alt + wheel = zoom where the mouse is · wheel = left / right (when zoomed) · Shift + wheel = rows · press the wheel and drag = move around · right-click a block = menu
Ctrl+= / Ctrl+− or + − zoom · Ctrl+0 or \ whole reel
Space play / pause · J back · K stop · L forward
← → one frame · Shift+← → one second · ↑ ↓ previous / next block · Home End
Click a block: pick it (details on the right) · double-click: play only that
Shift-click or drag a box: pick many · Ctrl+A all · Esc none
Delete remove · Ctrl+C / V copy / paste at the red line · Ctrl+X cut · Ctrl+D duplicate at the red line
Alt+← → nudge picked blocks one frame (Shift: 10 frames) · Enter play the picked block
Ctrl+Z undo · Ctrl+Shift+Z redo · S snap on / off (hold Alt while dragging)
Keyframes: click a piece / camera / caption = its ◆ row · drag a ◆ = new time · double-click a value lane = new ◆ · right-click a ◆ = curve · Delete / Ctrl+C / V / Alt+arrows work on picked ◆ too
M marker (right-click it on the ruler to remove) · [ ] previous / next marker · I / O loop start / end
Row M / S: mute / hear only that row here (the video file keeps every sound). Drag a row's bottom edge: taller / shorter. Drag the timeline's top edge: taller.
